# Repository scripts

`verify.mjs` runs dependency policy/audit checks, formatting, lint, whole-repository unit coverage, integration tests, the complete production build (including type checks), and browser acceptance in order. Run `npm run verify` from the repository root. Install the Playwright Chromium browser first with `npx playwright install chromium`.

`run-tests.mjs` recursively discovers test/spec files in workspace and tooling test directories, including TSX and ESM/CommonJS extensions. `npm run test:unit` excludes files in integration directories; `npm run test:integration` selects those files. `npm test` runs both. Empty suites fail. `coverage.mjs` inventories executable source and tooling files and enforces fresh >90% coverage for each metric in every file using only unit tests; run `npm run test:coverage`. See [testing architecture](../docs/TESTING.md) for suite ownership and fixtures.

Keep future repo-wide development, release, and deployment helpers here. Package-specific build commands belong in their workspace's `package.json`; database migrations and seeds belong in `database/`.

`precommit.mjs` implements `npm run precommit:check` and `npm run precommit:fix`. Check mode leaves source/index unchanged; fix mode applies ESLint/Prettier changes and reports remaining manual work. It runs type checks and all unit suites with fresh c8 coverage, rejects each changed executable file at or below 90% for any coverage metric, and checks JSDoc declarations using the TypeScript AST. `precommit-policy.mjs` contains scope, JSDoc and coverage rules. Gate regression tests use a disposable Git repository and real ESLint, Prettier, Node tests and c8.

`--staged` validates a reviewed index and refuses unstaged tracked files or untracked code/config that could affect results. Do not combine it with `--fix`. `npm run hooks:install` selects the versioned `.githooks/pre-commit` hook for this checkout. README and docs accuracy must also be reviewed through `$precommit-check` or repaired with `$precommit-fix`; the shell gate cannot verify semantic accuracy.

`check-dependency-policy.mjs` uses only Node built-ins and checks package manager configuration, exact dependency versions, and lockfile ownership. It runs on `preinstall` and through `npm run security:policy`. Its exported checker accepts a fixture root and command/environment adapters for unit testing the actual module. Integration tests use disposable directories and a local mock registry; they verify rejection of a one-day-old package, acceptance of an eight-day-old package, exact version saving, and rejection of weakened settings. `npm run test:policy` runs the tooling integration suite.

`google-drive.ts` implements `npm run drive:authorize` (a single-use local Google consent callback that writes the refresh token only to ignored `backend/.env`) and `npm run drive:check` (read-only account/root permission verification). Configure the Desktop OAuth client before authorizing; the callback listens on loopback port 53682 and expires after ten minutes. See [Google Drive setup](../docs/GOOGLE_DRIVE.md).
